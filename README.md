# Applis Croizat — benjaminhermand-max.github.io/appli-croizat

La boutique des applis de cours de M. Hermand (lycée Ambroise Croizat, Moûtiers).

## Ajouter une appli
Dans `index.html`, copier un bloc de la liste `APPS` et changer le nom, l'accroche, l'icône (à mettre dans `img/`), le lien et la description.
Penser à augmenter le numéro de version dans `sw.js` (`applis-croizat-v2`…).
