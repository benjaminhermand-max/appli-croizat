# Applis Croizat

La boutique des applis de cours de M. Hermand (lycée Ambroise Croizat, Moûtiers), façon Play Store.
En ligne sur https://benjaminhermand-max.github.io/appli-croizat/

## Ajouter une appli
1. Mettre son icône dans `img/` et ses captures dans `img/captures/` (`<id>-1.webp`, `<id>-2.webp`…, format téléphone).
2. Dans `index.html`, copier un bloc de la liste `APPS` et l'adapter (nom, accroche, lien, description, nombre de captures).
3. Augmenter le numéro de version dans `sw.js` (`applis-croizat-v3`…).
